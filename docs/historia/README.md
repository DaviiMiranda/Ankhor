# História

Comece pelo **[Enredo Principal](enredo_principal.md)**. Ele é a lei do projeto: história, mundo, personagens (com personalidade e arco de cada um), como a história chega ao jogador e tudo o que ainda está pendente. Se qualquer outro documento contradisser o Enredo, vale o Enredo.

| Onde | O que tem |
|---|---|
| [`enredo_principal.md`](enredo_principal.md) | A história inteira, em um só lugar |
| [`personagens/`](personagens/) | Uma ficha de produção por personagem: onde aparece, função no jogo, arte e arquivos |
| [`roteiro/`](roteiro/) | Roteiro das cutscenes |
| [`template_documento.md`](template_documento.md) | Modelo para escrever um bilhete, diário ou relatório novo |

Mudança de história entra **no mesmo PR** no Enredo Principal e em [`../decisoes.md`](../decisoes.md).
